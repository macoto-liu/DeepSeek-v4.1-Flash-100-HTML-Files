The set

Iterate z ↦ z² + c from zero. Some seeds wander, some settle, some are held forever.

The Mandelbrot set is the collection of complex numbers c for which that sequence stays bounded. Its rim is infinitely long and endlessly folded — a coastline that keeps arriving.
