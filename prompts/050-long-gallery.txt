Create a horizontal-scrolling gallery called "The Long Gallery", composed of six full-height art panels arranged along one long corridor. Each panel is a distinct abstract artwork made only from CSS: Dust (warm beige, a blurred sun, floating translucent planes), Tide (deep blue layered wave lines), Fold (off-white paper polygons with hard shadows), Signal (black with vertical neon bars), Bloom (crimson and pink radial petals) and Return (cream with a glowing arched doorway). Every panel carries a number, title, year and a short curator's note. A slim header shows the gallery name and current room count; arrow buttons and dots navigate; the page scrolls horizontally with snap, or via buttons and keyboard arrows. Fully responsive, one standalone HTML file with inline CSS/JS, no external images or fonts.
