Create a playful typographic bestiary called "Type Zoo". A cream editorial page presents twelve letters, each paired with a creature: A for Axolotl, B for Bear, C for Crane and so on. The letters are huge serif characters given small animal features — eyes, ears, a beak, a fin — and each card shows the species, Latin name and class. Filters (All, Mammals, Birds, Water, Reptiles) and a search field narrow the grid. Clicking a card opens a detail dialog with an enlarged letter, habitat, diet, voice and a short field note, plus previous/next navigation. Fully responsive, one standalone HTML file with inline CSS/JS, no external images or fonts.
